# Muhammad Ahsan Gulzar — Portfolio

Premium personal portfolio for a Digital Marketing Strategist & Medical Billing Specialist (15 years of experience).

**Stack:** TanStack Start (React 19, Vite), Tailwind CSS 4, lucide-react, Netlify (Image CDN, Forms).

## Run locally
```bash
npm install
npm run dev          # http://localhost:3000
netlify dev          # with Netlify feature emulation
```
Build: `npm run build` (publishes `dist/client`, configured in `netlify.toml`). Deploy by pushing to the connected Git repo.

## Editing content
All copy, services, projects, skills, experience, testimonials, and social links live in `src/content/site.ts`. Images are in `public/img/`.
